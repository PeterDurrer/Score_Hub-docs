# Screenshots

Dieser Ordner enthält die in den Anleitungen eingebundenen **SVG-Platzhalter**. Sie sind ausdrücklich keine echten Aufnahmen der Score_Hub-Oberfläche.

## Platzhalter ersetzen

1. Öffnen Sie Score_Hub in einer freigegebenen Test- oder Demo-Umgebung.
2. Verwenden Sie nur synthetische Konten, Vereine, Wettkämpfe und Resultate.
3. Nehmen Sie die Bildschirmaufnahme ohne private E-Mail-Adressen, reale Schützennamen, Zugangsdaten oder andere nicht benötigte personenbezogene Daten auf.
4. Ersetzen Sie die SVG-Datei durch einen aktuellen Screenshot und passen Sie den Bildpfad in der zugehörigen Markdown-Seite an (zum Beispiel `.png` oder `.webp`).
5. Aktualisieren Sie den Alternativtext und entfernen Sie den Hinweis auf den Platzhalter.

### Empfohlene Bildqualität

- PNG oder WebP, ausreichende Auflösung für Desktop und Mobilgeräte
- Bildschirmbereich auf die relevante Funktion zuschneiden
- Keine eingeblendeten Browser-Passwörter, Tokens oder privaten Browserprofile
- Keine erklärenden Markierungen, die wichtige Felder verdecken
