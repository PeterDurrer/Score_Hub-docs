# Screenshots

Die PNG-Dateien zeigen die Score_Hub-Oberfläche mit synthetischen Beispieldaten. Namen, Konten, Vereine und Resultate sind frei erfunden; es werden keine Produktionsdaten verwendet.

## Abbildungen

| Datei | Zugehörige Seite | Inhalt |
| --- | --- | --- |
| `dashboard.png` | `getting-started/dashboard.md` | Dashboard mit Schnellaktionen und Wettkampfliste |
| `club-profile.png` | `clubs/setup-club.md` | Vereinsstammdaten |
| `club-users.png` | `clubs/manage-members.md` | Vereinsbenutzer und Rollen |
| `competitions.png` | `competitions/create-competition.md` | Wettkampfliste und Erstellen-Dialog |
| `participants.png` | `competitions/manage-participants.md` | Schützenliste |
| `results-entry.png` | `results/quick-start.md` | Resultaterfassungsmaske |

| `statistics.png` | `rankings/statistics.md` | Statistiken eines Wettkampfs |

Die französischen und italienischen Ausgaben liegen jeweils in `fr/` und `it/` und werden von den lokalisierten Dokumentationsseiten verwendet.

## Pflege

Screenshots in PNG mit ausreichender Auflösung aufnehmen. Nur freigegebene Test- oder Demo-Umgebungen und synthetische Daten verwenden. Keine Zugangsdaten, privaten Browserprofile oder realen personenbezogenen Daten abbilden.
