# Wettkampf konfigurieren

Öffnen Sie **Verein → Wettkämpfe** und danach die Konfiguration des gewünschten Wettkampfs. Die Konfigurationsseite ist in Registerkarten unterteilt. Änderungen können die spätere Resultaterfassung und Ranglisten beeinflussen.

## Registerkarten

| Registerkarte | Wofür sie verwendet wird |
| --- | --- |
| Allgemein | Name, Typ, Status, Disziplin und Wettkampfzeitraum |
| Kategorien | Kategorien und zugehörige Wettkampf-Einstellungen |
| Resultatfelder | Felder, die bei der Resultaterfassung benötigt werden |
| Auszeichnungen | Auszeichnungen und Zuordnungen für den Wettkampf |
| Abrechnung | Abrechnungs- und Preisangaben, sofern eingerichtet |
| Runden | Runden anlegen und konfigurieren |
| Ranglisten | Ranglistenarten und deren Konfiguration |
| Benutzer | Benutzer und Rollen für diesen Wettkampf |

## Empfohlene Reihenfolge

1. Kontrollieren Sie die allgemeinen Wettkampfdaten und den Typ.
2. Richten Sie benötigte Kategorien und Runden ein.
3. Prüfen Sie die Resultatfelder. Die Erfassungsmaske richtet sich nach dieser Konfiguration.
4. Konfigurieren Sie Auszeichnungen und Ranglisten, soweit sie für den Wettkampf gebraucht werden.
5. Weisen Sie Wettkampfbenutzer und Rollen zu.
6. Erfassen Sie Testdaten nur in einem dafür vorgesehenen Testwettkampf.

Nicht jede Registerkarte ist für jeden Wettkampftyp oder jede Rolle gleich relevant. Falls eine Einstellung fehlt oder ausgegraut ist, bitten Sie die Wettkampfadministration um Unterstützung.
