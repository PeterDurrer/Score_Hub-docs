# Manuale utente di Score_Hub

Score_Hub aiuta le società a gestire tiratori, competizioni, risultati e classifiche. Questo manuale descrive le sezioni attualmente disponibili nell'applicazione. Le funzioni visibili dipendono dal proprio account e dai ruoli assegnati.

**È la prima volta che inserisci i risultati?** La [guida rapida per chi inserisce i risultati](getting-started/result-scorer-quick-start.md) spiega il primo accesso con cambio della password e dati della società, nonché l'inserimento quotidiano fino alla classifica.

## Procedura tipica

1. Accedere con il proprio account utente.
2. Nella dashboard, selezionare la società o la sezione della competizione desiderata.
3. Configurare una competizione con i dati di base e le impostazioni necessarie.
4. Inserire i tiratori partecipanti e, se necessario, i gruppi.
5. Inserire e verificare i risultati.
6. Controllare le classifiche ed esportarle in PDF se necessario.

Non tutti i passaggi sono disponibili per ogni ruolo. Se manca una voce di menu o un'azione non è disponibile, rivolgersi all'amministrazione della società o del sistema competente.

## Lingua e dispositivo

L'applicazione consente di scegliere tra tedesco, francese e italiano. Le pagine di questo manuale sono attualmente disponibili in italiano. La disposizione può variare in base alle dimensioni dello schermo; denominazioni e funzioni restano le stesse.

## Domande o problemi?

Consulta prima le [domande frequenti](faq.md). Per le autorizzazioni mancanti, contatta l'amministrazione della società. Per problemi tecnici, utilizza il contatto di supporto messo a disposizione dalla tua organizzazione per Score_Hub.
