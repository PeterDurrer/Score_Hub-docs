# Sostituire gli screenshot

Le illustrazioni del manuale sono attualmente **segnaposto**, non schermate reali dell'interfaccia Score_Hub. I file sorgente si trovano nella cartella `screenshots/`.

## Sostituire i segnaposto con immagini reali

1. Apri Score_Hub in un ambiente di test o demo autorizzato.
2. Usa account, società, competizioni e risultati di esempio.
3. Acquisisci la schermata senza indirizzi e-mail privati, nomi reali di tiratori, credenziali o altri dati personali non necessari.
4. Sostituisci il file SVG con uno screenshot aggiornato e modifica il percorso dell'immagine nella pagina Markdown corrispondente (ad esempio `.png` o `.webp`).
5. Aggiorna il testo alternativo e rimuovi l'avviso relativo al segnaposto.
