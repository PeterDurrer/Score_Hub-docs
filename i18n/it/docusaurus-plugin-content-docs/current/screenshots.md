# Screenshot e aggiornamento

Le immagini mostrano l'interfaccia Score_Hub con dati dimostrativi sintetici. Account, nomi, società e risultati sono fittizi; non vengono utilizzati dati di produzione.

## Aggiornare gli screenshot

1. Apri Score_Hub in un ambiente di test o demo autorizzato.
2. Usa account, società, competizioni e risultati di esempio.
3. Acquisisci la schermata senza indirizzi e-mail privati, nomi reali di tiratori, credenziali o altri dati personali non necessari.
4. Salva lo screenshot in formato PNG nella cartella `screenshots/`, quindi aggiorna il percorso e il testo alternativo nelle versioni linguistiche della pagina Markdown corrispondente.
