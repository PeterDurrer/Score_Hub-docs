# Glossario

| Termine | Spiegazione |
| --- | --- |
| Società | Organizzazione a cui sono associati utenti, poligoni e competizioni. |
| Competizione | Evento con configurazione, partecipanti, risultati e classifiche propri. |
| Tiratore della competizione | Tiratore associato a una competizione specifica. |
| Categoria | Suddivisione eventualmente utilizzata durante l'inserimento dei risultati e la creazione delle classifiche. |
| Turno | Sezione di una competizione per cui vengono configurati e inseriti i risultati. |
| Campo risultato | Valore o informazione aggiuntiva utilizzata nell'inserimento dei risultati di una competizione. |
| Classifica | Prospetto dei risultati calcolato in base alla configurazione della competizione. |
| Ruolo della società | Autorizzazione assegnata a un utente all'interno di una società. |
| Ruolo della competizione | Autorizzazione assegnata a un utente all'interno di una singola competizione. |
| Ruolo di sistema | Ruolo globale che determina i diritti di amministrazione a livello di sistema. |

Il punteggio specifico, compresi i valori degli anelli, i campi aggiuntivi e i riconoscimenti, è determinato dalla configurazione della competizione. Per i termini regolamentari sportivi si applicano le regole ufficiali della competizione in questione.
