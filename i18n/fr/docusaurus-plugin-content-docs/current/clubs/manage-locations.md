# Gérer les sites du club

Dans la section **Sites**, les utilisateurs autorisés peuvent consulter les sites du club actuellement sélectionné et, selon leurs droits, en créer ou en modifier. Le formulaire de l’application indique les champs disponibles.

## Créer ou modifier un site

1. Ouvrez la section du club et accédez à **Sites**.
2. Choisissez **Ajouter** ou ouvrez un site existant pour le modifier.
3. Renseignez soigneusement les informations disponibles, par exemple le nom et l’adresse.
4. Enregistrez, puis vérifiez l’entrée dans la liste des sites.

Ne renseignez que les informations effectivement proposées dans le formulaire. Ce guide ne considère pas les horaires d’ouverture, les réservations en ligne, l’inventaire des équipements, les photos ni les calendriers de maintenance comme des fonctionnalités disponibles.

## Un site ne s’affiche pas

- Vérifiez que le bon club est sélectionné.
- Vérifiez que votre rôle autorise la modification.
- Rechargez la page. Si le problème persiste, signalez-le à l’administration en indiquant le nom du club et du site.
