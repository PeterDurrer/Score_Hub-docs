# Guide d’utilisation de Score_Hub

Score_Hub aide les clubs à gérer les tireurs, les concours, les résultats et les classements. Ce guide décrit les fonctionnalités actuellement disponibles dans l’application. Les fonctionnalités visibles dépendent de votre compte et des rôles qui vous sont attribués.

## Déroulement habituel

1. Connectez-vous à votre compte.
2. Dans le tableau de bord, sélectionnez le club ou la section de concours approprié.
3. Configurez un concours avec les données de base et les paramètres nécessaires.
4. Ajoutez les tireurs participants et, si nécessaire, les groupes.
5. Saisissez et vérifiez les résultats.
6. Vérifiez les classements et exportez-les au format PDF si nécessaire.

Toutes les étapes ne sont pas accessibles à chaque rôle. Si une entrée de menu est absente ou qu’une action n’est pas disponible, contactez l’administration du club ou du système compétente.

## Langue et appareil

L’application permet de choisir entre l’allemand, le français et l’italien. Les pages de ce guide sont actuellement en français. La disposition de l’interface peut varier selon la taille de l’écran ; les libellés et les fonctionnalités restent les mêmes.

## À propos des captures d’écran

Les illustrations du guide sont actuellement identifiées comme des **images de remplacement**. Il ne s’agit pas de véritables captures de l’application. Consultez [Remplacer les captures d’écran](screenshots.md) pour savoir comment réaliser des captures à jour dans le respect de la confidentialité.

## Questions ou problèmes ?

Consultez d’abord la [foire aux questions](faq.md). En cas d’autorisations manquantes, contactez l’administration de votre club. Pour les problèmes techniques, utilisez le contact d’assistance Score_Hub communiqué par votre organisation.
