# Compte et connexion

## Obtenir un accès

Connectez-vous avec votre adresse e-mail et votre mot de passe. L’option d’inscription de la page de connexion ne permet actuellement pas de créer librement un compte en libre-service. Si vous n’avez pas encore de compte ou si votre club n’est pas correctement associé à votre compte, adressez-vous à l’administration de votre club.

Si l’administration vous transmet un lien d’inscription direct, le formulaire demande les informations suivantes :

- Prénom et nom
- Adresse e-mail
- Club
- Mot de passe et confirmation du mot de passe

Le mot de passe doit comporter au moins huit caractères. Les indications de validation affichées dans le formulaire prévalent.

## Se connecter

1. Ouvrez la page de connexion de Score_Hub.
2. Saisissez l’adresse e-mail de votre compte et votre mot de passe.
3. Sélectionnez **Se connecter**. Si un changement de mot de passe est requis, suivez d'abord les étapes de la section [Première connexion et changement de mot de passe](#erster-passwortwechsel). Sinon, vous accédez au tableau de bord.

Si la connexion échoue, vérifiez d’abord l’adresse e-mail et l’orthographe du mot de passe. Si un message d’erreur de connexion à la base de données s’affiche également, le problème ne vient probablement pas de vos identifiants. Dans ce cas, contactez l’administration.

## Se déconnecter

Ouvrez le menu utilisateur et sélectionnez **Se déconnecter**. Après avoir utilisé un appareil partagé, déconnectez-vous systématiquement.

## Première connexion et changement de mot de passe {#erster-passwortwechsel}

Pour un compte créé par l'administration système et après une réinitialisation par celle-ci, vous devez changer le mot de passe initial ou temporaire reçu après vous être connecté. Vous ne pouvez pas continuer à utiliser Score_Hub avant ce changement.

1. Connectez-vous avec votre adresse e-mail et le mot de passe reçu.
2. Sur la page **Changement de mot de passe requis**, saisissez le mot de passe reçu dans **Mot de passe actuel**.
3. Saisissez un nouveau mot de passe d'au moins huit caractères, puis saisissez-le une seconde fois pour le confirmer.
4. Sélectionnez **Changer le mot de passe**. Vous êtes redirigé vers la page de connexion : reconnectez-vous avec votre nouveau mot de passe.

Si vous ne connaissez pas le mot de passe reçu, utilisez [Mot de passe oublié](#mot-de-passe-oublie) ou contactez l'administration système.

## Changer le mot de passe dans le profil

Si vous êtes connecté et connaissez votre mot de passe actuel, ouvrez votre **Profil**, puis la section **Changer le mot de passe**. Saisissez votre mot de passe actuel et deux fois le nouveau mot de passe, puis sélectionnez **Changer le mot de passe**. Après la modification, vous êtes déconnecté : reconnectez-vous avec le nouveau mot de passe.

Le changement dans le profil nécessite le mot de passe actuel. Si vous l'avez oublié, utilisez plutôt [Mot de passe oublié](#mot-de-passe-oublie).

## Mot de passe oublié {#mot-de-passe-oublie}

Si vous avez oublié votre mot de passe, vous pouvez le réinitialiser vous-même :

1. Sur la page de connexion, sélectionnez **Mot de passe oublié ?**.
2. Saisissez l'adresse e-mail de votre compte et effectuez la vérification de sécurité affichée.
3. Sélectionnez **Demander un lien**. Pour des raisons de sécurité, la même confirmation s'affiche toujours, qu'un compte soit associé ou non à l'adresse.
4. Ouvrez l'e-mail **Réinitialiser le mot de passe** et suivez le lien. Le lien est valable une heure et ne peut être utilisé qu'une seule fois.
5. Sur la page **Définir un nouveau mot de passe**, saisissez deux fois votre nouveau mot de passe (au moins huit caractères), puis sélectionnez **Enregistrer le mot de passe**.
6. Après le message de confirmation, sélectionnez **Retour à la connexion** et connectez-vous avec votre nouveau mot de passe.

**Vous n'avez pas reçu d'e-mail ?** Vérifiez votre dossier de courrier indésirable et assurez-vous que l'adresse saisie correspond à celle enregistrée dans votre compte. Un e-mail n'est envoyé que pour les comptes actifs, dans la langue définie dans le profil. Trop de demandes rapprochées peuvent temporairement empêcher l'envoi ; réessayez plus tard. Si le problème persiste ou si la vérification de sécurité n'est pas disponible, contactez l'administration système.

**Lien invalide ou expiré ?** Demandez-en un nouveau. Dès qu'un nouveau lien est créé, les liens précédents deviennent invalides.

**Vous n'êtes pas à l'origine de la demande ?** Ignorez l'e-mail : votre mot de passe reste inchangé.

## Réinitialisation par l'administration système {#admin-passwort-reset}

Seuls les administrateurs système peuvent définir directement un nouveau mot de passe pour un compte ; cette action n'est pas disponible dans la gestion des utilisateurs du club.

1. En tant qu'administrateur système, ouvrez **Admin → Utilisateurs** et recherchez le compte concerné.
2. Dans sa ligne, sélectionnez **Réinitialiser le mot de passe** et vérifiez l'adresse e-mail affichée.
3. Dans la fenêtre **Définir un nouveau mot de passe**, saisissez deux fois un mot de passe temporaire d'au moins huit caractères. Sélectionnez **Réinitialiser le mot de passe** et vérifiez le message de confirmation.
4. Transmettez le mot de passe temporaire à la personne concernée par un moyen sécurisé. Cette opération n'envoie pas automatiquement de lien de réinitialisation.
5. La personne se connecte avec ce mot de passe et définit son propre mot de passe comme indiqué sous [Première connexion et changement de mot de passe](#erster-passwortwechsel).

Un changement ou une réinitialisation de mot de passe invalide les sessions existantes et les liens de réinitialisation encore valides. Les personnes concernées doivent se reconnecter sur leurs appareils. Ne partagez jamais votre mot de passe personnel ni un lien de réinitialisation.
