# Compte et connexion

## Obtenir un accès

Connectez-vous avec votre adresse e-mail et votre mot de passe. L’option d’inscription de la page de connexion ne permet actuellement pas de créer librement un compte en libre-service. Si vous n’avez pas encore de compte ou si votre club n’est pas correctement associé à votre compte, adressez-vous à l’administration de votre club.

Si l’administration vous transmet un lien d’inscription direct, le formulaire demande les informations suivantes :

- Prénom et nom
- Adresse e-mail
- Club
- Mot de passe et confirmation du mot de passe

Le mot de passe doit comporter au moins huit caractères. Les indications de validation affichées dans le formulaire prévalent.

## Se connecter

1. Ouvrez la page de connexion de Score_Hub.
2. Saisissez l’adresse e-mail de votre compte et votre mot de passe.
3. Sélectionnez **Se connecter**. Une fois la connexion réussie, vous accédez au tableau de bord.

Si la connexion échoue, vérifiez d’abord l’adresse e-mail et l’orthographe du mot de passe. Si un message d’erreur de connexion à la base de données s’affiche également, le problème ne vient probablement pas de vos identifiants. Dans ce cas, contactez l’administration.

## Se déconnecter

Ouvrez le menu utilisateur et sélectionnez **Se déconnecter**. Après avoir utilisé un appareil partagé, déconnectez-vous systématiquement.

## Profil et mot de passe

Dans la section **Profil**, vous pouvez modifier vos informations personnelles et définir votre propre mot de passe sous **Changer le mot de passe**. Saisissez votre mot de passe actuel (le mot de passe initial reçu lors de la première connexion), puis saisissez deux fois le nouveau mot de passe pour le confirmer. Sélectionnez **Changer le mot de passe** et vérifiez le message de confirmation.

Cette procédure ne permet pas de réinitialiser un mot de passe oublié. L’interface de connexion actuelle ne propose pas de fonction de réinitialisation sans connexion ni de confirmation par e-mail. Si vous avez oublié vos identifiants, demandez à l’administration quelle procédure suivre.
