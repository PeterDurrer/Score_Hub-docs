# Glossaire

| Terme | Explication |
| --- | --- |
| Club | Organisation à laquelle sont rattachés les utilisateurs, les stands et les concours. |
| Concours | Événement avec sa propre configuration, ses participants, ses résultats et ses classements. |
| Tireur du concours | Tireur rattaché à un concours donné. |
| Catégorie | Division pouvant être utilisée lors de la saisie et de l’établissement des classements. |
| Manche | Partie d’un concours pour laquelle les résultats peuvent être configurés et saisis. |
| Champ de résultat | Valeur ou information complémentaire utilisée pour un concours lors de la saisie des résultats. |
| Classement | Vue des résultats calculée selon la configuration du concours. |
| Rôle du club | Autorisation d’un utilisateur au sein d’un club. |
| Rôle du concours | Autorisation d’un utilisateur au sein d’un concours donné. |
| Rôle système | Rôle global définissant les droits d’administration à l’échelle du système. |

Le barème appliqué — notamment les valeurs des séries, les champs supplémentaires et les distinctions — est déterminé par la configuration du concours. Pour les termes relatifs aux règles sportives, les règles officielles du concours concerné font foi.
