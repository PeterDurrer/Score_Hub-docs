# Vereinsstandorte verwalten

Es gibt zwei getrennte Standortansichten:

- Im Vereinsbereich unter **Standorte** sehen berechtigte Benutzer die Standorte des aktuell ausgewählten Vereins. Vereinsadministratoren können diese Standorte anlegen und bearbeiten.
- Systemadministratoren verwenden die systemweite **Standortverwaltung**. Sie können Standorte aller Vereine durchsuchen und bearbeiten sowie beim Anlegen den zugehörigen Verein auswählen.

Ein Standort bleibt seinem Verein zugeordnet; beim Bearbeiten kann der Verein nicht gewechselt werden. Welche Felder verfügbar sind, zeigt das jeweilige Formular der Anwendung.

## Standort anlegen oder bearbeiten

1. Öffnen Sie den Vereinsbereich und wechseln Sie zu **Standorte**.
2. Wählen Sie **Hinzufügen** oder öffnen Sie einen bestehenden Standort zur Bearbeitung.
3. Füllen Sie die verfügbaren Angaben sorgfältig aus, zum Beispiel Name und Adresse.
4. Speichern Sie und kontrollieren Sie anschliessend den Eintrag in der Standortliste.

Pflegen Sie nur Angaben, die das Formular tatsächlich anbietet. Öffnungszeiten, Online-Buchungen, Ausstattungsinventar, Fotos und Wartungspläne werden in dieser Anleitung nicht als verfügbare Funktionen vorausgesetzt.

## Standort wird nicht angezeigt

- Vergewissern Sie sich, dass Sie den richtigen Verein ausgewählt haben.
- Prüfen Sie, ob Ihre Rolle die Bearbeitung erlaubt.
- Laden Sie die Seite erneut. Bleibt der Fehler bestehen, melden Sie ihn der Administration mit Vereinsname und Standort.
