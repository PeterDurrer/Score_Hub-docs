# Konto und Anmeldung

## Zugang erhalten

Die Anmeldung erfolgt mit Ihrer E-Mail-Adresse und Ihrem Passwort. Die Registrierungsoption auf der Anmeldeseite ist derzeit nicht als öffentlicher Selbstbedienungsprozess verfügbar. Wenn Sie noch kein Konto haben oder Ihre Vereinszuordnung fehlt, wenden Sie sich an die für Ihren Verein zuständige Administration.

Falls Sie von der Administration einen direkten Registrierungslink erhalten, enthält das Formular diese Angaben:

- Vorname und Nachname
- E-Mail-Adresse
- Verein
- Passwort und Passwortbestätigung

Das Passwort muss mindestens acht Zeichen lang sein. Die im Formular angezeigten Validierungshinweise haben Vorrang.

## Anmelden

1. Öffnen Sie die Score_Hub-Anmeldeseite.
2. Geben Sie die E-Mail-Adresse Ihres Kontos und das Passwort ein.
3. Wählen Sie **Anmelden**. Wenn ein Passwortwechsel erforderlich ist, folgen Sie zuerst den Schritten unter [Erste Anmeldung und Passwortwechsel](#erster-passwortwechsel). Andernfalls gelangen Sie zum Dashboard.

Wenn die Anmeldung fehlschlägt, prüfen Sie zuerst E-Mail-Adresse und Schreibweise des Passworts. Wird zusätzlich ein Datenbankverbindungsfehler angezeigt, liegt das Problem wahrscheinlich nicht an Ihren Zugangsdaten. Wenden Sie sich dann an die Administration.

## Abmelden

Öffnen Sie das Benutzermenü und wählen Sie **Abmelden**. Melden Sie sich auf gemeinsam genutzten Geräten nach der Arbeit immer ab.

## Erste Anmeldung und Passwortwechsel {#erster-passwortwechsel}

Bei einem von der Systemadministration neu angelegten Konto und nach einem administrativen Passwort-Reset müssen Sie das erhaltene Start- beziehungsweise Ersatzpasswort nach der Anmeldung ändern. Bis dahin können Sie Score_Hub nicht weiter verwenden.

1. Melden Sie sich mit Ihrer E-Mail-Adresse und dem erhaltenen Passwort an.
2. Auf der Seite **Passwortänderung erforderlich** geben Sie unter **Aktuelles Passwort** das erhaltene Passwort ein.
3. Geben Sie ein neues Passwort mit mindestens acht Zeichen ein und bestätigen Sie es durch erneute Eingabe.
4. Wählen Sie **Passwort ändern**. Sie werden zur Anmeldung zurückgeleitet und melden sich mit Ihrem neuen Passwort erneut an.

Falls Sie das erhaltene Passwort nicht kennen, nutzen Sie [Passwort vergessen](#passwort-vergessen) oder kontaktieren Sie die Systemadministration.

## Passwort im Profil ändern

Wenn Sie bereits angemeldet sind und Ihr aktuelles Passwort kennen, öffnen Sie Ihr **Profil** und den Abschnitt **Passwort ändern**. Geben Sie Ihr aktuelles Passwort und das neue Passwort zweimal ein und wählen Sie **Passwort ändern**. Nach erfolgreicher Änderung werden Sie abgemeldet; melden Sie sich mit dem neuen Passwort erneut an.

Die Passwortänderung im Profil setzt das aktuelle Passwort voraus. Wenn Sie es vergessen haben, verwenden Sie stattdessen [Passwort vergessen](#passwort-vergessen).

## Passwort vergessen {#passwort-vergessen}

Wenn Sie Ihr Passwort vergessen haben, können Sie es selbst zurücksetzen:

1. Wählen Sie auf der Anmeldeseite **Passwort vergessen?**.
2. Geben Sie die E-Mail-Adresse Ihres Kontos ein und schliessen Sie die angezeigte Sicherheitsprüfung ab.
3. Wählen Sie **Link anfordern**. Aus Sicherheitsgründen wird immer dieselbe Bestätigung angezeigt – unabhängig davon, ob zur Adresse ein Konto existiert.
4. Öffnen Sie die E-Mail **Passwort zurücksetzen** und folgen Sie dem Link. Der Link ist eine Stunde gültig und kann nur einmal verwendet werden.
5. Geben Sie auf der Seite **Neues Passwort festlegen** Ihr neues Passwort zweimal ein (mindestens acht Zeichen) und wählen Sie **Passwort speichern**.
6. Nach der Erfolgsmeldung gelangen Sie über **Zurück zur Anmeldung** zur Anmeldeseite. Melden Sie sich mit dem neuen Passwort an.

**Keine E-Mail erhalten?** Prüfen Sie den Spam-Ordner und ob die eingegebene Adresse mit der im Konto hinterlegten übereinstimmt. Nur für aktive Konten wird eine E-Mail versendet. Die E-Mail wird in der in Ihrem Profil eingestellten Sprache versendet. Zu viele Anfragen innerhalb kurzer Zeit können den Versand vorübergehend verhindern; versuchen Sie es später erneut. Wenn das Problem bestehen bleibt oder die Sicherheitsprüfung nicht verfügbar ist, wenden Sie sich an die Systemadministration.

**Link ungültig oder abgelaufen?** Fordern Sie einen neuen an. Sobald ein neuer Reset-Link erstellt wird, sind vorherige Reset-Links ungültig.

**Anfrage nicht selbst gestellt?** Sie können die E-Mail ignorieren – Ihr Passwort bleibt unverändert.

## Passwort durch die Systemadministration zurücksetzen {#admin-passwort-reset}

Nur Systemadministratoren können ein Passwort direkt für ein Konto neu setzen; die Vereinsbenutzerverwaltung bietet diese Aktion nicht.

1. Öffnen Sie als Systemadministrator **Admin → Benutzer** und suchen Sie das gewünschte Konto.
2. Wählen Sie in dessen Zeile **Passwort neu setzen** und prüfen Sie die angezeigte E-Mail-Adresse.
3. Geben Sie im Dialog **Neues Passwort vergeben** ein Ersatzpasswort mit mindestens acht Zeichen zweimal ein. Wählen Sie **Passwort neu setzen** und prüfen Sie die Erfolgsmeldung.
4. Übermitteln Sie das Ersatzpasswort der betroffenen Person auf einem sicheren Weg. Bei diesem Vorgang wird kein Reset-Link automatisch versendet.
5. Die Person meldet sich mit dem Ersatzpasswort an und legt wie unter [Erste Anmeldung und Passwortwechsel](#erster-passwortwechsel) beschrieben ein eigenes Passwort fest.

Eine Passwortänderung oder ein Reset macht bestehende Anmeldesitzungen und noch offene Reset-Links ungültig. Betroffene Personen müssen sich auf ihren Geräten erneut anmelden. Geben Sie weder das persönliche Passwort noch einen Reset-Link an andere Personen weiter.
