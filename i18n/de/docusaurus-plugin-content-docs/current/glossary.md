# Glossar

| Begriff | Erklärung |
| --- | --- |
| Verein | Organisation, der Benutzer, Standorte und Wettkämpfe zugeordnet sind. |
| Wettkampf | Veranstaltung mit eigener Konfiguration, Teilnehmenden, Resultaten und Ranglisten. |
| Wettkampfschütze | Ein Schütze, der einem bestimmten Wettkampf zugeordnet ist. |
| Kategorie | Einteilung, die bei der Erfassung und Ranglistenbildung verwendet werden kann. |
| Runde | Abschnitt eines Wettkampfs, für den Resultate konfiguriert und erfasst werden. |
| Resultatfeld | Wert oder Zusatzangabe, die in der Resultaterfassung für einen Wettkampf verwendet wird. |
| Rangliste | Nach der Konfiguration des Wettkampfs berechnete Übersicht der Ergebnisse. |
| Vereinsrolle | Berechtigung eines Benutzers innerhalb eines Vereins. |
| Wettkampfrolle | Berechtigung eines Benutzers innerhalb eines einzelnen Wettkampfs. |
| Systemrolle | Globale Rolle, die systemweite Verwaltungsrechte festlegt. |

Die konkrete Wertung – einschliesslich Ringwerten, Zusatzfeldern und Auszeichnungen – wird durch die Wettkampfkonfiguration bestimmt. Bei sportlichen Regelbegriffen gelten die offiziellen Regeln des jeweiligen Wettkampfs.
